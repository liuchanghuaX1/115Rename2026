# 115Rename2026

> **版本：2.1.2**

一款专为 115 网盘设计的视频文件智能整理与标准化重命名工具。支持本地番号加工、多站在线刮削（含 FC2 专用查询）、中文翻译、演员补全、JavDB 评分同步、按演员/前缀分桶归档，并内置完整的备份与对比导出功能。

---

## ✨ 主要功能

### 🧹 本地番号加工
- 精准提取番号，支持 **长厂牌前缀**（`MXVR`、`SIVR`、`T28`、`S2M`、`300MAAN` 等）及数字混合厂牌
- **智能分段识别**：  
  - 支持 `Part1`、`CD2`、`Vol.3`、`EP4`、`Pt.5`、`SP`、`SPECIAL` 等常见标记  
  - 带数字的分段（如 `sp1`、`part1`）统一转换为 `-1`、`-2` 等；纯字母分段（如单独的 `sp`）保留为 `-SP`  
  - 支持 `_1`、`.2`、`空格3`、`1of2`、`上/下/前/后` 等多种格式
- 自动清除 **域名前缀**（如 `www.98T.la@`）和广告标识
- **标记智能保留**：`4K`、`8K`、`60fps`、`120fps`、`中文字幕`、`无码`、`流出` 等自动转为 `【】` 标记
- 最终文件名格式：`番号-分段 标题 女优名 【标记】_日期.后缀`

### 🌐 多站联网改名
- **普通番号查询顺序**：JavDB → JavBus（JavBus 失败时回退无码站）  
- **FC2 查询顺序**：JavDB → MissAV（通过 Recombee API） → FC2PPVDB  
- **智能演员补全**：当主源缺少演员信息时，自动调用备用源补充，确保归档准确性  
- **全局缓存**：命中番号信息后持久化存储（90 天 TTL），减少重复请求

### 🌏 中文翻译
- 新增 **“改名(中文翻译)”** 菜单项  
- 翻译顺序：DeepL（免费端点） → MyMemory（备用）  
- 翻译失败自动回退原标题，**绝不阻塞批量任务**  
- 演员名和番号信息不会发送至翻译服务，保护隐私

### 📁 归档整理
- **FC2 统一归档**：所有 `FC2-PPV-*` 番号自动归入 `FC2` 文件夹  
- **普通番号按演员归档**：自动查询演员信息，创建对应演员文件夹并移动文件  
- **分桶归档（番号前缀数字段）**：按番号前缀和千位数字区间创建文件夹（如 `SSIS-0000-0999`）  
- 支持**设置归档根目录**（右键文件夹 → 设为归档根目录）

### ⭐ JavDB 评分同步
- 从 JavDB 抓取影片评分（1~5 星）  
- 自动同步到 115 网盘文件星级，便于后续筛选

### 💾 备份与对比导出
- **备份文件名**：选中文件后可导出文件名列表为 TXT 或复制到剪贴板  
- **改名对比导出**：改名完成后可选择导出 **“旧文件名 → 新文件名”** 对照表（TXT 或剪贴板）

### ⚡ 高效并发与进度
- 本地加工并发 **5**，联网改名并发 **3**  
- 右下角实时显示处理进度条，支持**暂停/继续**任务

## 📋 使用方法

1. 登录 [115 网盘](https://115.com/)，进入文件列表  
2. 选中需要处理的文件或文件夹（可多选）  
3. 在 **更多** 菜单（右键菜单或顶部按钮）中点击以下任一操作：  
   - **本地番号加工**：仅利用文件名自身信息进行标准化（无需联网）  
   - **改名(多网站轮询)**：在线获取标题、演员、日期并重命名  
   - **改名(中文翻译)**：在线获取信息后额外翻译标题（保留原日文标题）  
   - **归档至文件夹**：按演员或 FC2 分类自动归档  
   - **分桶归档(番号前缀数字段)**：按前缀及数字区间创建文件夹归档  
   - **设为归档根目录**：右键文件夹 → 设为归档根（归档操作的顶级目录）  
   - **获取javdb评分**：批量同步选中影片的评分  
   - **备份文件名**：导出当前选中文件的原始名称  
4. 任务执行时右下角显示进度条，可随时暂停/继续

## 🚀 安装方法

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展  
2. 点击下方链接直接安装，或复制脚本内容到 Tampermonkey 新建脚本：  
   - [安装链接](https://raw.githubusercontent.com/liuchanghuaX1/115Rename2026/main/115Rename2026.user.js)  
3. 确保脚本已启用，刷新 115 网盘页面即可看到新增菜单项

---

## ⚠️ 注意事项

- 请确保 Tampermonkey 中已授予脚本访问以下域名的权限（`@connect` 已声明）：  
  `javbus.com`、`javlibrary.com`、`xslist.org`、`javdb.com`、`fc2ppvdb.com`、`webapi.115.com`、`client-rapi-missav.recombee.com`、`oneshot-free.www.deepl.com`、`api.mymemory.translated.net`  
- 翻译功能依赖外部免费接口，若超时或失败将自动使用原标题，不影响任务连续性  
- 脚本仅作用于文件名，**不会修改文件内容或元数据**，请放心使用  
- 若 115 网盘界面更新导致菜单未显示，请尝试刷新页面或切换到旧版界面（可能需等待适配）
