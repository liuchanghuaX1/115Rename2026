# 115Rename2026

> **版本：3.0.0（大更新）**

一款专为 115 网盘设计的视频文件智能整理与标准化重命名工具。本次 3.0.0 版本迎来了**史诗级重构**，全面接入 **JAV老司机刮削引擎**，并重构了番号识别与 UI 注入逻辑，带给你极致稳定、快速的整理体验。

---

## 🌟 3.0.0 重大更新亮点

- **🚀 双源混合刮削，永不失效**：优先请求“JAV老司机”的中转 API（自带防 CF 盾、秒级响应）；若未安装老司机或其失效，将**自动无缝降级**为脚本内置的直连引擎，彻底告别“未找到”！
- **🛡️ 番号算法多级兜底**：引入全新的正则与多级容错机制，彻底解决 `SIVR-324-8K-cd1`、`SONE-084-4K-60FPS` 等复杂后缀无法识别、或误把“8K”识别成“分段”的世纪难题。
- **🎨 新旧版 115 菜单完美对齐**：彻底重构右键菜单注入，强隔离样式防止被 115 原生 CSS 污染。新旧版 115 都拥有一致的 SVG 图标和完美的垂直对齐。
- **🌓 预览面板**：全面适配暗黑模式。
- **⚙️ 设置面板功能**：增加完整的多源开关排序、以及自定义分隔符设置，界面交互更顺滑。

---

## ✨ 主要功能

### 🌐 强大的联网改名与刮削
- **混合刮削源**：优先借用老司机 API，内置 JavDB / JavBus / JavLibrary / Xslist / FC2PPVDB / MissAV / Avsox / AVMoo 等 8 大源并发兜底。
- **中文翻译**：调用 DeepL / MyMemory 免费接口，自动翻译日文标题，失败绝不阻塞批量任务。
- **演员补全**：自动识别并补全影片演员信息。

### 🧹 智能本地番号加工
- 支持 **长厂牌前缀**（`MXVR`、`SIVR`、`T28`、`S2M`、`300MAAN` 等）及数字混合厂牌。
- **智能分段识别**：支持 `Part1`、`CD2`、`Vol.3`、`EP4`、`SP` 等，统一转换为 `-cd1` 等格式。
- **标记智能保留**：`4K`、`中文字幕`、`无码` 等自动转为 `【】` 标记后缀。
- **保护手动命名**：如果文件名中已包含你手动修改的中文标题，脚本会自动跳过以防覆盖。

### 📁 多种归档整理模式
- **按演员归档**：自动查询演员信息，在归档根目录下创建对应演员文件夹并移入。
- **分桶归档**：按番号前缀和千位数字区间创建文件夹（如 `SSIS-0000-0999`）。
- **FC2 统一归档**：所有 `FC2-PPV-*` 统一归入 `FC2` 文件夹。

### ⭐ 评分同步与对比导出
- **JavDB 评分同步**：一键批量抓取评分并同步至 115 网盘星级。
- **改名对比导出**：批量改名完成后，可一键导出或复制“旧名 → 新名”的对照 TXT 列表。

## 📋 使用方法

1. 登录 [115 网盘](https://115.com/)，进入文件列表。
2. 勾选需要处理的文件或文件夹。
3. 在右键菜单中点击对应功能：
   - **本地番号规范**：仅利用文件名自身信息进行标准化。
   - **联网改名 / 中文标题**：在线获取标题、演员并重命名（可选翻译）。
   - **归档至文件夹 / 分桶归档**：自动移动文件到分类目录。
   - **设为归档根目录**：选中目标文件夹右键设置。
   - **获取javdb评分**：批量同步评分。
4. 所有任务均支持右下角进度条实时查看，**支持中途暂停/继续**。
5. 快捷键：打开 Tampermonkey 菜单 → **⚙️ 设置**，可自定义字段顺序、刮削源、归档根目录等。

## ⚠️ 注意事项

- 脚本仅作用于文件名，**不会修改文件内容或元数据**。
- 翻译功能依赖外部免费接口，失败会自动回退原标题。
- **极速体验建议**：建议同时安装 [JAV老司机-新](https://github.com/ZiPenOk/scripts) 脚本，本脚本会自动借用其接口，实现如丝般顺滑的刮削。
