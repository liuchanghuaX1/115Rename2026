# 115Rename2026

> **版本：2.0.0**

一款专为 115 网盘设计的视频文件智能整理与标准化重命名工具。**已全面适配 115 新版界面**，支持本地番号加工、多站在线刮削、中文翻译、演员补全、JavDB 评分同步、按演员/前缀分桶归档，并内置完整的备份与对比导出功能。

---

## ✨ 主要功能

### 🆕 全面适配 115 新版界面
- **现代化右键菜单**：自动注入新版 115 的悬浮菜单（右侧“更多”按钮），图标与字号完美对齐官方样式
- **新旧版兼容**：向下兼容旧版 115（`li[rel="item"]` / `.file-list-item` / `data-file-id` 等自适应识别）
- **原生 UI 融入**：无违和感插入，支持深色模式自动适配

### ⚙️ 可视化设置面板（v2.0 新增）
通过 Tampermonkey 菜单 → **⚙️ 115Rename 设置** 打开：
- **字段顺序与开关**：`番号 → 标题(原) → 标题(中) → 女优 → 日期` 可自由上下移动、启用/停用（番号固定第一项）
- **分隔符自定义**：字段分隔符 / 日期前缀 / 女优分隔符
- **选项开关**：翻译中文标题 / 附加【中字/无码】等标记 / 保护手动命名 / 分段使用 cd 前缀
- **右键菜单可见性**：8 个右键菜单项可单独隐藏
- **刮削源勾选**：8 个数据源自由开关（JavDB / JavBus / JavLibrary / Xslist / FC2PPVDB / MissAV / Avsox / AVMoo）
- **并发数调节**：改名并发 1-10
- **归档根目录**：支持路径输入（如 `/归档` 或 `/我的资源/归档`），路径不存在自动创建

### 🧹 本地番号加工
- 精准提取番号，支持 **长厂牌前缀**（`MXVR`、`SIVR`、`T28`、`S2M`、`300MAAN` 等）及数字混合厂牌
- **智能分段识别**：支持 `Part1`、`CD2`、`Vol.3`、`EP4`、`Pt.5`、`SP`、`SPECIAL` 等，统一转换为 `-cd1` 或 `-sp` 等
- 自动清除 **域名前缀**（如 `www.98T.la@`）和广告标识
- **标记智能保留**：`4K`、`8K`、`60fps`、`120fps`、`中文字幕`、`无码`、`流出` 等自动转为 `【】` 标记
- **v3.0.2 修复**：
  - `www.98T.la@FC2-PPV-4251578.H265.mp4` 不再被误识别为 `FC2-PPV-4251578-cd59` 或 `..mp4`
  - 纯标点残留（如 `.`、`-`）不再进入文件名

### 🌐 多站联网改名
- **普通番号查询顺序**：JavDB → JavBus → JavLibrary → Xslist（并行请求，第一个成功即用）
- **FC2 查询顺序**：JavDB → MissAV（Recombee API） → FC2PPVDB
- **无码查询顺序**：Avsox → AVMoo → JavBus Uncensored
- **智能演员补全**：主源缺演员信息时自动调用备用源补充
- **全局缓存**：命中番号信息后持久化存储（默认 90 天 TTL，可在设置调整）

### 🌏 中文翻译
- **翻译顺序**：DeepL（免费端点）→ MyMemory（备用）
- 翻译失败自动回退原标题，**绝不阻塞批量任务**
- 演员名和番号信息不会发送至翻译服务

### 📁 归档整理
- **FC2 统一归档**：所有 `FC2-PPV-*` 番号自动归入 `FC2` 文件夹
- **普通番号按演员归档**：自动查询演员信息，创建对应演员文件夹并移动文件
- **分桶归档**：按番号前缀和千位数字区间创建文件夹（如 `SSIS-0000-0999`）
- **归档根目录支持三种设置方式**：
  - 右键文件夹 → `设为归档根目录`
  - 设置面板 → 输入路径（如 `/归档/SSIS`），自动解析并创建
  - 一键清除（回退到网盘根目录）

### ⭐ JavDB 评分同步
- 从 JavDB 抓取影片评分（1~5 星）
- 自动同步到 115 网盘文件星级，便于后续筛选

### 💾 备份与对比导出
- **备份文件名**：选中文件后导出文件名列表为 TXT 或复制到剪贴板
- **改名对比导出**：改名完成后可选择导出 **"旧文件名 → 新文件名"** 对照表

### ⚡ 高效并发与进度
- 改名并发默认 3（可在设置调整 1-10）
- 右下角实时显示处理进度条，支持**暂停/继续**
- 顶部/右侧浮动提示归档根目录状态

## 📋 使用方法

1. 登录 [115 网盘](https://115.com/)，进入文件列表（**推荐使用新版界面**）
2. 选中需要处理的文件或文件夹（可多选）
3. 在 **更多** 菜单（新版界面右上角“更多”按钮或右键菜单）中点击以下任一操作：
   - **本地番号加工**：仅利用文件名自身信息进行标准化（无需联网）
   - **改名(多网站轮询)**：在线获取标题、演员、日期并重命名
   - **改名(中文翻译)**：在线获取信息后额外翻译标题（保留原日文标题）
   - **归档至文件夹**：按演员或 FC2 分类自动归档
   - **分桶归档**：按前缀及数字区间创建文件夹归档
   - **设为归档根目录**：选中文件夹右键 → 设为归档根
   - **获取javdb评分**：批量同步选中影片的评分
   - **备份文件名**：导出当前选中文件的原始名称
4. 任务执行时右下角显示进度条，可随时暂停/继续

### 高级：自定义设置

打开 Tampermonkey 菜单 → **⚙️ 115Rename 设置**：
- 拖动 `↑` / `↓` 调整字段顺序
- 取消勾选隐藏不需要的字段或右键菜单项
- 勾选/取消勾选刮削源
- 输入归档根目录路径后点击「解析并保存」

## ⚠️ 注意事项

- 请确保 Tampermonkey 中已授予脚本访问以下域名的权限（`@connect` 已声明）：
  `javbus.com`、`javlibrary.com`、`xslist.org`、`javdb.com`、`fc2ppvdb.com`、`webapi.115.com`、`client-rapi-missav.recombee.com`、`oneshot-free.www.deepl.com`、`api.mymemory.translated.net`、`avsox.host`、`avmoo.host`
- 翻译功能依赖外部免费接口，若超时或失败将自动使用原标题，不影响任务连续性
- 脚本仅作用于文件名，**不会修改文件内容或元数据**，请放心使用
- **保护手动命名**：如果文件名中已经包含你手动添加的标题（非纯番号），脚本会跳过不覆盖（可在设置中关闭）
