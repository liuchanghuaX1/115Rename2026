# 115Rename2026

> 版本：**1.12.3**

一款专为 115 网盘设计的视频整理与标准化重命名脚本。支持本地加工与多站在线刮削，并集成了 **中文翻译**、**FC2 专用查询**、**智能演员补全**、**评分同步** 以及 **按演员归档** 等强大功能。

## ✨ 主要功能

### 🧹 本地番号加工
- 精准提取番号，支持长厂牌前缀（`MXVR`、`SIVR` 等）及 `T28`、`S2M` 等数字混合厂牌
- 分段智能识别：`Part1`、`Pt.2`、`CD3`、`Vol.5`、`No.6` 以及 `_1`、`.2` 等格式统一转换为 `-1`、`-2`
- 自动清除 `@` 前的广告前缀（如 `www.98T.la@`）
- 标记智能保留：`4K`、`8K`、`60fps`、`120fps`、`中文字幕`、`无码`、`流出` 等自动转化为【】标记
- 文件名格式统一：`番号-分段 标题 女优名 【标记】_日期.后缀`

### 🌐 多站改名（在线刮削）
- **普通番号查询顺序**：JavDB → JavBus
- **FC2 查询顺序**：JavDB → MissAV → FC2PPVDB
- 当主查询源缺少演员信息时，自动调用备用源补全女优名
- 同名番号信息全局缓存，避免重复请求

### 🌏 中文翻译
- 新增“改名(中文翻译)”按钮
- 翻译顺序：DeepL → MyMemory
- 翻译失败自动回退原标题，绝不中断批量任务
- 演员名不会发送给翻译接口，保护隐私

### 📁 归档整理
- **FC2 统一归档**：所有 FC2/PPV 番号自动移动到 `FC2` 文件夹
- **普通番号按演员归档**：查询演员信息后自动创建对应演员文件夹并移动文件
- 支持设置归档根目录

### ⭐ JavDB 评分同步
- 从 JavDB 获取影片评分
- 自动更新到 115 网盘的文件星级

### 💾 备份与对比
- **备份文件名**：选中文件后可导出文件名列表为 TXT 或复制到剪贴板
- **改名对比导出**：改名完成后可选择导出“旧文件名 → 新文件名”对照表

### ⚡ 高效并发
- 本地加工并发 5，联网改名并发 3
- 实时进度条显示处理状态

## 📋 使用方法

1. 登录 115 网盘，选中需要处理的文件或文件夹（可多选）
2. 在 **更多** 菜单中点击相应按钮：
   - **本地番号加工**：仅使用文件名自身信息标准化（无需联网）
   - **改名(多网站轮询)**：在线获取标题、女优、日期并重命名
   - **改名(中文翻译)**：在线获取信息后额外翻译标题（保留原标题）
   - **归档至文件夹**：按演员或 FC2 分类自动归档
   - **设为归档根目录**：右键文件夹设置归档根
   - **获取javdb评分**：批量同步评分
   - **备份文件名**：导出当前选中文件名
3. 处理过程中可实时查看右下角进度条

## 🚀 安装方法

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 点击脚本的 `@downloadURL` 直接安装，或手动复制脚本内容到 Tampermonkey 新建脚本中
3. 确保脚本已启用，刷新 115 网盘页面

## ⚠️ 注意事项

- 请确保 Tampermonkey 中已允许脚本访问 `javbus.com`、`javdb.com`、`fc2ppvdb.com`、`missav` 等域名（`@connect` 权限）
- 翻译功能依赖外部免费接口，可能受限于接口稳定性，失败时自动使用原标题
